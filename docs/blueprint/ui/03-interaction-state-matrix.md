# UI 状态机与交互合同

## 全局状态字典
| State | 用户文案 | 必需交互 |
|---|---|---|
| LOADING | 正在读取，预计不确定 | 骨架屏、取消（合理时）、防止重复提交 |
| EMPTY | 尚无 Node / Plugin / Log | 下一步明确，不能造样本 |
| READY | 已验证并就绪 | 展示实际 `observed_at` |
| DEGRADED | 部分实例不可用 | 标记受影响范围、跳转诊断 |
| UNREACHABLE | 无法联系节点 | 最近见证时间、不要标记 STOPPED |
| UNKNOWN | 无法确认操作结果/实例状态 | 不得自动重试有副作用动作，提供重新核验 |
| PARTIAL | 查询/部署结果部分成功 | 明确分母与失败对象，保持用户已输入数据 |
| FORBIDDEN | 无对应权限 | 说明需要哪类权限，不暴露秘密 |
| CONFLICT | 代次变动或版本冲突 | 显示最新版本和重试风险 |
| FAILED | 已确认失败 | 精确失败阶段、请求 ID、重试/回滚路径 |

## 核心场景矩阵
| 场景 | 正常 | 网络/权限失败 | 特殊 |
|---|---|---|---|
| Upload | 验签后可 Stage | 签名/包格式不合法拒绝 | 欠缺依赖可查看详情 |
| Activate | Ready 后切路由 | 新版启动失败保留旧版 | DB迁移不兼容阻止 |
| Disable | 取消有效路由 | 依赖阻止并解释 | 运行请求 Drain 有截止时刻 |
| Node detail | 最近采样 | 失联展示 observedAt | 资源指标 stale 不等于 zero |
| Live Logs | 持续更新 | 断线尝试手动恢复 | Gap、转轮替换、超速丢弃 |
| Permissions | 版本化授权 | 403 无隐式重试 | grant 变更及时撤销在内存的令牌视图 |
| Upgrade old tab | v1/v2 兼容窗口 | 不兼容接口明确通知 | 未保存表单确认再重载 |

## 命令幂等规则
每次有副作用动作分配 `requestId`，如果传输失败标记 `UNKNOWN`，必须先用 requestId 查询状态；服务端保留命令摘要，不允许客户端自动生成新的 requestId 盲重试。权限变更后缓存必须失效，正在加载的页面不得用旧身份继续更新新用户状态。

## 高风险确认文案
- Upgrade：影响 {插件}/{当前版本}->{目标版本}，是否新增权限/修改数据结构、旧版如何保留？
- Disable：将撤销哪些 capability，受影响消费者有哪些？
- Uninstall：停止并移除运行制品，**业务数据默认仍保留**。
- Purge：不可逆删除范围/备份/审批人；不与 Uninstall 共用简单确认弹窗。
