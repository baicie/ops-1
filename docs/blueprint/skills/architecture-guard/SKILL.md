# Skill: architecture-guard

## 触发条件
跨模块新能力、修改 Kernel 公共协议、增加依赖/服务时

## 必需输入
设计文档、受影响的模块和接口、替代方案

## 执行步骤
1. 确认 Kernel vs Plugin 所有权，绘制依赖方向
2. 列出数据契约、权限、兼容性和故障模式
3. 比较最小插件方案与新增内核代码方案
4. 形成 ADR 及测试契约、拒绝无需求的微服务/消息中间件

## 必交产物
ADR、模块边界图、风险清单、最小验收用例

## 退出条件
内核不出现业务 DTO；批准后的契约可供两端独立实现

## 禁止事项
不伪造运行测试、截图、客户日志或生产部署结果；缺失信息明确标记并阻塞相应验收。
