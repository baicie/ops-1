# 项目执行 Skills（平台无关流程）

每个 `SKILL.md` 是团队成员或任意开发助手可以执行的一份任务 Runbook。使用约定：**触发条件 → 必需输入 → 步骤 → 输出产物 → 退出条件**。不需要特定编辑器或 Agent 产品识别；也可由项目脚本/人工审阅执行。

- `architecture-guard`：新模块/跨插件 API/增加 Kernel 能力前使用。
- `plugin-design`：设计插件 Manifest、权限、版本、依赖、迁移。
- `distributed-fault-review`：节点/网关/任务故障与恢复审查。
- `ui-page-design`：用户任务与布局方案。
- `ui-visual-audit`：浏览器截图、人机交互与响应式评测。
- `security-review`：安全信任边界和攻击面验收。
- `data-contract-review`：未来 Schema、Data Source、Pipeline 数据语义。
- `release-gate`：版本发布质量审查。

- `oci-release-review`：镜像、签名、SBOM 与静态资产发布审查。
- `multilang-conformance`：Java/Go/TS 以及未来语言同一 Plugin Runtime v1 合约。
