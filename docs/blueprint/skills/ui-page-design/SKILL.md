# Skill: ui-page-design

## 触发条件
新页面、新表格/Drawer、导航或关键表单开始编码前

## 必需输入
JTBD、用户角色、业务数据契约、状态矩阵

## 执行步骤
1. 定义一个首要任务、主要 CTA 和下一步跳转
2. 画出 1440/1024/390 布局、信息层级与 Empty/Loading/Error
3. 检查使用共享 Tokens/组件与最少动态布局
4. 补全权限、部分失败、未知/过期数据和危险操作确认
5. 编写组件和浏览器验收计划

## 必交产物
页面任务说明、线框、状态矩阵、组件复用表

## 退出条件
先获交互设计批准，再写页面代码

## 禁止事项
不伪造运行测试、截图、客户日志或生产部署结果；缺失信息明确标记并阻塞相应验收。
