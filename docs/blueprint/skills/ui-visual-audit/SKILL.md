# Skill: ui-visual-audit

## 触发条件
页面完工/布局改动/主题改变/提测前

## 必需输入
真实浏览器 URL、非敏感测试数据、六种 viewport/theme

## 执行步骤
1. 生成 1440/1024/390 × light/dark 真实截图
2. 查拥挤/间距/对齐/卡片堆叠/CTA/表格响应式
3. 用键盘完成主任务，检查焦点、对话框、错误与滚动
4. 检查状态文案是否和 API UNKNOWN/STALE/NO_DATA 一致
5. 按 P0/P1/P2 登记问题，修复后重测并附前后对照

## 必交产物
截图集、审查评分、问题和修复证据

## 退出条件
建议分数 ≥85 且无 P0/P1，实际浏览器复验通过

## 禁止事项
不伪造运行测试、截图、客户日志或生产部署结果；缺失信息明确标记并阻塞相应验收。
