# G13-B1.2 Automation Principal Security

- 日期：2026-11-07
- 基线：`main` `72a656e`
- 分支：`fix/g13-b1.2-principal-security`
- 结论：**PASS**。Claims 与数据库权威行完全绑定；`owa2` 使用 Ed25519，插件只持公钥。

## 1. Finding：插件持有 `owa1` 的 HMAC key

`automation.rs` 的签名 key 与 `OPSWEAVE_CALLER_CONTEXT_KEY` 相同（`HMAC(cursor_secret,"caller-context:"+pluginId)`）。插件已经持有该 key，因此它**有能力**重新计算任意 `owa1` 签名；“签发端点只允许 Node”只约束正常调用，不构成密码学上的唯一签名者。

攻击前提：攻击者是插件进程/能读取其环境。它可拿到一个合法 token，修改 claims 并重签。

### 修复前的问题（代码审查确认）

`authenticate()` 只比较 `jti/plugin/instance/node/generation/workspace/source/allowed_ops`，**没有**比较：

- `row.expires_at` 与 `claims.expires_at`（可延长 token 寿命）
- `row.issued_at`
- `row.event_id` / `row.incident_id`（可改绑）
- `row.budget`（可伪造声明，但执行端读 DB，影响有限）

## 2. 已实施：全量 claim ↔ row 绑定

`authenticate()` 现在额外要求：

- token 生命周期 `0 < expires_at - issued_at <= 300s`；
- `row.expires_at > now()`（DB 过期即使 claims 未过期也拒绝）；
- `row.issued_at == claims.issued_at`、`row.expires_at == claims.expires_at`；
- `row.event_id == claims.event_id`、`row.incident_id == claims.incident_id`；
- `budget` **不**绑定：它是可变的（每次采集扣减），执行端只读数据库 budget，token 里的副本不参与授权；绑定它会让合法重试失败。
- 原有 jti/plugin/instance/node/generation/workspace/source/allowed_ops/revoked/source READY 检查不变。

因此，即使插件重签，只要改动了任何字段，Kernel 会以 `AUTOMATION_PRINCIPAL_INVALID` 拒绝；重签“原样 claims”不会获得超出该行的任何权限。

### 攻击测试

`automation::tests::forged_claims_with_the_shared_key_are_refused_by_the_stored_row`（真实 PostgreSQL）：

1. 正常签发 principal，解码 claims；
2. 使用同一签名 key 重签 `expires_at + 3600` → 拒绝；
3. 重签 `budget.collections=9999` → 接受但无效（执行端读 DB budget）；
4. 重签 `event_id` → 拒绝；
5. 原样 claims 重签 → 接受（证明拒绝来自 row 绑定，而不是签名损坏）。

## 3. 已完成：签名权隔离（B1.2b）

`owa2` 改为 Ed25519：Kernel 私钥由 cursor secret 派生且不离开 Kernel；插件仅收到公钥。插件持有的 caller-context HMAC key 无法伪造 `owa2`。

建议最小方案：**Ed25519**。

- Kernel 从 `cursor_secret` 派生 Ed25519 seed（不新增持久 Secret），私钥不离开 Kernel；
- `owa2` token = payload + Ed25519 signature；
- 插件只收到 `OPSWEAVE_AUTOMATION_PUBLIC_KEY`（公钥）用于验证，不能签发；
- 保留 `owa1` 验证一个迁移窗口，或直接切换（当前无外部消费者）；
- 攻击测试改为：插件持有 caller key 也无法伪造 `owa2` 签名。

攻击测试：用 caller key 构造 HMAC `owa2` 被签名验证拒绝。
