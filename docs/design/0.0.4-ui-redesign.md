# 0.0.4 UI/UX Redesign — Audit & Design System

Status: implemented on `feat/0.0.4-ui-redesign`; visual gates run in Playwright.

## 2. Design language

Modern developer platform / enterprise observability: high information density,
quiet surfaces, one accent, semantic status colors, clear hierarchy. No gradients,
glow, decorative textures or duplicated UI frameworks.

### Typography

| Token | Usage | Size |
|---|---|---|
| Display / Page Title | page H1 | 22–26px, 700 |
| Section Heading | panel H2 | 16px, 650 |
| Body | primary content | 13.5px |
| Secondary | descriptions | 12px |
| Caption / Label | metadata, uppercase labels | 11px |
| Monospace Data | IDs, digests, config | 11–13px |

### Spacing / Radius

```text
space:  4 / 8 / 12 / 16 / 24 / 32 / 48
control radius: 6px
card radius: 10px
dialog radius: 12px
```

### Color

Existing semantic tokens are retained and extended:

```text
bg / surface / surface-2 / surface-3
border / border-strong / text / text-secondary / text-muted / text-tertiary
accent / accent-soft / focus
ok / warn / danger / info + soft variants
canvas-bg / edge (graph-specific)
```

Dark mode sets equivalent semantic values; no per-page hex colors were added.

### Components

Existing `Button`, `Input`, `Table`, `Badge`, `Panel`, `EmptyState`,
`ErrorState`, `Skeleton` are reused. No second UI framework was introduced.

## 3. Studio Workspace

```text
┌──────────────────────────────────────────────────────┐
│ Pipeline identity · draft state · actions              │
├──────────┬───────────────────────────────┬───────────┤
│ Node     │        WORKFLOW CANVAS         │ Inspector │
│ Palette  │                                │           │
├──────────┴───────────────────────────────┴───────────┤
│ Preview console (toggle)                               │
└──────────────────────────────────────────────────────┘
```

- ≥1200px: global navigation becomes a 64px icon rail so canvas keeps primary space.
- 1440: canvas > 700px wide, fills available height.
- 1080: palette hidden, inspector remains; canvas 540px.
- ≤760: single column; canvas 420px; inspector below; toolbar horizontally scrollable.
- Preview lives in a toggleable console; no fake cancel button.
- Auto Layout re-applies deterministic linear positions without changing the IR.

## 4. Node / edge visual language

- 202px node card: category icon, human label, node ID, 2-line config summary.
- Category tint: Source info, Transform accent, Validate success, Sink warning.
- Neutral border by default; accent only selected; hover border.
- Input ports left, output ports right, 8px handles, labels separate from handles.
- Smoothstep edges, semantic edge token, selected/hover edge highlight.
- Delete removes attached edges; undo/redo and dirty baseline preserved.

## 5. Pipeline / Job hierarchy

- Pipeline Detail: 4 metric cards (Revision, Nodes, Latest Run, Updated); flow step strip;
  revisions; recent-job table with bounded UUID.
- Job History: search, pipeline filter, status filter, bound UUID column.
- Job Detail: pipeline name H1; status/revision/short ID subtitle; status/attempts/
  pipeline/revision metrics; Full UUID/Fence/Lease in Advanced; Timeline; Attempts;
  Checkpoints; Result.
- UUIDs and digests are never primary headings; full values remain accessible via
  title/Advanced/Copy.

## 6. Responsive / Dark / A11y

- Breakpoints: 1440 / 1280 / 1024 / 760 / 620 / 390.
- Mobile tables become labelled cards; table containers remain the only horizontal
  scroll region on desktop.
- Dark surfaces use semantic tokens; graph background/edge tokens have dark values.
- Visible focus, labels for inputs, `aria-label` for icon actions, `aria-label` canvas,
  `title` on truncated IDs.
- Reduced Motion disables non-essential transitions.
- Dirty navigation shows `beforeunload` warning.
- Remaining A11y debt: full dialog focus trap and delete confirmation.
