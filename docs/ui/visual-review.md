## Review notes

- The navigation keeps **Platform** and **Extensions** separate. A signed plugin contributes only its own navigation item; it cannot add a Kernel route.
- State words are not merged: `UNKNOWN` is a dashed gray badge, `UNREACHABLE` is danger, `DEGRADED` is warning, `READY/ACTIVE` are green. Color is never the only signal (icon + text).
- Tables switch to labelled stacked rows below 760 px; the 390 px screenshots retain status/action meaning instead of hiding columns.
- The log viewer uses a bounded monospace surface, explicit pause/follow distinction, gap banner and copy action. It does not render ANSI/HTML from untrusted log text.
- The install wizard separates signature verification, permission review, placement and activation; it never auto-advances past a failed signature.
- Dark mode uses separate tokens and was reviewed at all three widths; no white-on-white or inverse-color artifacts observed.
- Remaining visual follow-ups (P2): plugin display names are derived from IDs for external packages; long image digests intentionally truncate with a copy affordance; a dedicated settings-page visual treatment can be added after the first design-system freeze.
