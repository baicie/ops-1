# Q-07 测试/发布规则

- MUST：单元、契约、集成、三机 E2E、失败注入、授权负例和视觉审查分别记录“是否真实运行”。
- MUST：0.0.1 发布需 real Linux Node A/B、真实 OCI 引擎、PG、Kernel/Web、Hello v1/v2，不能只测 Mock。
- MUST：制品 digest、构建依赖锁、公开 SBOM、安全扫描、版本兼容矩阵与发布说明归档。
- MUST：发现数据不兼容/签名不可信/权限不全/失联状态歧义立即停止激活，不以 Warning 继续。
- MUST：回滚至少覆盖二进制/路由；若 Schema 不可向下兼容，阻止假回滚并提供人工恢复手册。
- Gate：打 Tag 之前保留所有真实检查日志、环境版本、截图、签名与测试失败列表；任何未执行项目记 `NOT_RUN`。
