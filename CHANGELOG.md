# Changelog

## 0.0.1 — Platform Foundation

- Rust Kernel with PostgreSQL desired/observed/effective state, RBAC, audit and operation receipts.
- Signed plugin bundles, immutable registry, lifecycle: stage, deploy, activate, disable, enable, upgrade, rollback, uninstall.
- Node Runtime with Docker OCI adapter, enrollment, heartbeat, health probes, resource limits and private data proxy.
- Two Node Runtime reference placement, readiness-gated Gateway routing, signed log cursors and SSE.
- React Shell with dynamic signed remote extensions, Ops Center, responsive design system and Bootstrap Diagnostics.
- Java 21 Spring Boot, Go and TypeScript Runtime v1 hello plugins with real OCI images.
- `opsctl` recovery CLI, contract validation, runtime conformance, two-node failover and Playwright visual tests.
